# FLEXORA

Modern daily stretching & mobility web app — stronger competitor to Bend.

## Features

- **SVG pose illustrations** (clean stick-figure style for every move)
- **Difficulty levels**: Beginner / Intermediate / Advanced
- **Body area filters** + Body Radar
- **Full Hebrew + RTL** (toggle EN / עב)
- **Custom Builder with Drag & Drop** reorder
- Voice guidance (TTS)
- Streaks, Flexometer, localStorage progress
- PWA-ready

## Run

Open `index.html` on mobile or desktop browser.

Or:
```bash
npx serve .
```
